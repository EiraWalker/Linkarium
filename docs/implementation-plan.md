# 实施顺序与验收计划

2026-10-09。本文件保留交付顺序、证据和完整退出条件；应用已实现，逐项实际结果与尚未达成的条件见 [实现与验收记录](implementation-status.md)。总体入口为 [完整技术方案](technical-plan.md)。

## 1. 先验证什么

最高不确定性是动态网页状态是否能固化为满足首屏视觉目标的 Monolith HTML，以及受限环境能否同时保证浏览器正常运行和隔离。先完成这两个原型，再进入完整界面集成；基础 CRUD 和视觉壳可以并行开发，但不能将未验证归档接入后宣称项目完成。

## 4. 有意义的自动化测试

### 数据与服务

- 用真实 SQLite 连接测试唯一约束、目录环、父级删除与共享文件引用，不用只模拟 ORM 返回的测试替代。
- 并发提交相同 URL、同名目录和相同任务，证明只产生一个有效记录/任务；两个设备以旧 revision 修改时返回明确冲突。
- 验证数据库 router 和迁移命令：auth/session/axes/维护表仅在 state，业务表仅在 library；测试不存在跨库 FK。
- 快照发布在写临时文件、rename 后、DB commit 前后各注入退出；验证无指向缺失文件的正常成功记录、孤儿可回收、同 attempt 不重复历史。
- 日期测试使用可注入时钟；失败重试和到期扫描不能形成密集死循环。

### HTTP 与前端

- API 契约测试覆盖认证、CSRF、输入边界、revision、HTTP 状态和批量原子性。
- 前端用可控浏览器 fixture 覆盖点击星标与卡片事件分离、URL 查询状态、弹层焦点和过期响应丢弃。
- 浏览器端到端测试覆盖真实登录→导入→搜索→详情→刷新→历史→校对→备份恢复主路径；手机真实触屏或等效浏览器自动化后，再做实际手机验证。
- iframe 测试必须使用产品实际鉴权端点和 CSP，不以裸本地 HTML 的截图替代；直接打开快照 URL 也不得执行脚本。

测试工具使用 Django 自带测试框架/标准库、TypeScript 类型检查及已有 Playwright 工具链中的浏览器测试能力，避免首版维护重复的浏览器测试框架。实现时按官方文档锁版本；本文不表示已经安装或运行测试。

### 外部输入与恢复

- 网页文本包含“忽略规则/泄露密钥/创建目录”等内容时，AI 结果仍被当数据处理，不能自动执行目录变更。
- AI 返回未知 ID、额外字段、超长路径或非法 JSON 时，保留网页和当前目录，错误可重试而不写入假分类。
- ZIP 路径穿越、重复条目、解压炸弹、缺失 Artifact、错误 hash、未来 schema、恶意 SQLite trigger 等包在候选区被拒绝。
- 恢复前备份失败、磁盘不足、控制器在各阶段退出时，当前库仍可恢复；所有旧任务和过期会话失效。
- 恢复包更改 AI endpoint 而 profile UUID 不变时，当前密钥不得自动发送到新地址。

## 5. 性能测量目标

以下是初始工程目标，尚非实测保证。报告记录机器 CPU/RAM/磁盘、浏览器版本、样本 HTML 大小、网络条件和并发；不能用空白卡片推算真实网页预览成本。

| 项目 | 初始目标/测量方式 |
| --- | --- |
| 规模 | 1000 个网站、两种设备、多个历史版本；超出规模仅提示 |
| 元数据 API | 在明确记录的本地测试机上，常用查询 p95 目标 ≤300ms，不含外站抓取 |
| UI | 搜索/选择/批量操作不等待后台采集；输入无持续主线程阻塞 |
| 预览加载与保留 | 当前分页全部完成加载，并发 2/1；滚动与应用内导航不重载；相同快照反复访问不重复创建；记录不同快照首次保留的资源增长 |
| 抓取吞吐 | 记录每种设备 p50/p95 时间、成功率、HTML 大小与峰值内存；用实测决定调度跨度 |
| 常驻资源 | 浏览器空闲后确实退出；Web、worker、控制器分别记录内存，不只统计 Python 进程 |
| 备份恢复 | 分别测小库/含多轮历史库的冻结时长、空间放大和恢复重启；不承诺固定耗时 |

浏览器模拟移动尺寸与真实 iOS/Android 设备验收分别报告。目标浏览器为桌面 Chrome/Firefox、Android Chrome、iOS Safari 的实施时受支持稳定版；截图采集统一 Chromium，不能据此承诺 Safari 排版完全相同。

## 6. 主要风险与处理门槛

| 风险 | 处理方案 | 何时阻断交付 |
| --- | --- | --- |
| 某些动态状态不能固化 | P0 分类验证，记录具体缺失，反馈技术选择 | 核心页面首屏缺失而未达成调整共识时，不声称快照能力完成 |
| 出网/文件隔离无法落实 | 宿主受控 launcher；非 root 浏览器；独立 namespace/cgroup | 隔离旁路测试失败或只能用 privileged/关闭 sandbox 跑通时 |
| 手机多 HTML 内存偏高 | 加载并发限制、分页、详情优先、会话结束和数据失效时释放；保留范围遵循 ADR-0009 | 实际手机反复崩溃/明显不可用时，需调整预算与呈现 |
| 全历史导致容量增长 | 显示用量、空间预检、人工清理；禁止自动淘汰 | 磁盘不足仍继续写入或损坏已有库时 |
| AI 质量或协议不兼容 | 测试配置、严格校验、候选人工确认、人工整理后备流程 | 模型输出可直接改目录、旧建议可覆盖新整理时 |
| 恢复与 worker 并发 | 维护控制器停进程、切 generation、epoch 失效 | 未确认旧进程退出就切库或原位替换正在打开的 DB 时 |
