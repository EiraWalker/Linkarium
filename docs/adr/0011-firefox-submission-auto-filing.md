# 为 Firefox 主动收藏增加独立的自动归档策略

2026-10-20，用户取消浏览器书签同步，确认只支持 Firefox，通过工具栏提交当前页面的 URL 和标题，由 Linkarium 后台 AI 分类并直接归档。

复用现有收藏、采集、任务队列、共享分类体系和方案确认领域操作。以业务库中的独立插件提交记录持久保存自动应用权限、库身份、收藏及目录版本、关联任务和结果；只授权该入口新建的单个收藏。状态查询不排任务，重复网址保留原记录。分类应用与方案状态、工作流终态、任务完成在同一事务执行，过期结果不能覆盖人工整理。

相比把所有新增收藏的分类都改成自动确认，该方案保留原有人工校对语义，也能单独恢复插件流程。相比增加常驻本机服务和新插件 Token，Firefox 通过固定 Linkarium 站点的内容脚本复用网页登录会话与 CSRF；需要时复用或创建一个普通站点标签页作为短暂传输桥，服务器接受后无需保持标签页。

运行身份／供应商凭据与业务库继续按 ADR-0007 隔离。ADR-0008 的本机管理工具仍只生成待审核建议，本次例外不扩大其权限。对不支持的浏览器、离线队列、第三方站点登录内容和书签库同步不增加扩展设计。
