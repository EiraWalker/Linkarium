## 由实施确定的技术默认值

URL 等价规则、数据 schema 与迁移、桌面/手机采集视口、页面等待与超时、任务去重/重试/计时、分页及同时挂载预览数量、多设备同时修改策略、会话期限和密码重置执行、进程守护与打包方式，仍需形成具体实现方案。它们不意味着技术栈重新待选；影响产品语义的变更再交用户确认。

例如 URL 规则不可擅自去掉查询参数而合并不同页面；采集视口不可擅自改变已确认的桌面/手机独立快照原则。

## 必须验证的技术可行性

动态网页的 HTML 归档和受限重放能否达到用户的视觉一致目标，仍是关键验证项。需验证真实页面、复杂浏览器状态、两种设备布局以及多卡片性能。保存 HTML 或进程成功退出不代表保真通过；若验证失败，应反馈具体差异，再讨论技术调整，不自动降低目标。

浏览器导入兼容、登录鉴权、历史清理引用、任务恢复和一千条规模也未经过实现验收。它们是待验证项，不属于未作产品选择。
