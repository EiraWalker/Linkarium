# 用两份本地 SQLite 隔离运行身份与可恢复收藏库

2026-10-09，用户授权完整技术规划并已要求整库覆盖恢复。为避免恢复业务备份时覆盖当前登录身份、会话和 AI 凭据，将运行状态保存在 `state.sqlite3`，收藏、快照历史、分类及业务任务保存在独立的 `library.sqlite3`；两者仍是同机 SQLite 文件，不增加数据库服务。

这细化并替代 ADR-0005 中“所有数据放一个 SQLite 文件”的部分，前后端框架与单 worker 保持原选型。Django 路由和迁移须显式指定数据库，禁止跨库外键；备份只导出业务库，恢复在维护窗口切换完整业务 generation。代价是多库路由测试和恢复编排，换取运行凭据不会随收藏库回滚的清晰边界。此决定是技术规划，尚未实现验收。
