# 通过缓存页面截图展示网站预览

此为历史决定，已由 0004-monolith-html-snapshots.md 取代。用户最新指定快照使用 Monolith，不使用 PNG 图片；本文件的截图用语不再代表当前方案。

2026-10-09，用户明确预览只需看到最新页面，并选择缓存截图作为多网站展示的形式。收藏界面的页面预览采用缓存首屏截图；同屏展示多个网站时无需为每个收藏保持可交互网页运行。最新决定将默认定时刷新从每天改为每周一次，并允许每个网站单独配置刷新间隔，同时支持用户主动刷新一个文件夹内的网页。刷新在后台逐个执行，展示进度；失败时保留旧截图并标记失败。定时执行规则和文件夹是否递归刷新仍待确认；已有截图只代表最近一次成功抓取时的页面内容，不能保证与此刻的网站完全一致。
