# 本机收藏库自动化管理的首版边界

2026-10-11。为支持本机 Codex 和脚本管理收藏库，首版管理 API 仅供本机调用，覆盖链接、文件夹、标签、备注、后台任务、快照和 AI 分类。用户选择了这一明确范围，而非软件的全部管理功能；导入导出、软件设置、AI 服务凭据配置、备份恢复、清空和重置不属于本次首版交付范围。

用户进一步选择复用软件密码登录及其会话，不引入独立管理 Token。因此上述边界是本次管理工具和 Skill 的功能范围；已有 owner 会话仍具有软件原有权限，不能将工具仅提供部分命令描述为服务端权限隔离。

用户最终明确要求账号密码以明文保存于本地，取消此前建议的 Windows 加密凭据保存，会话失效后自动重新登录，并提供清除凭据命令。后端 HTTP API 必须扩展自动化所需语义，不能仅在 CLI 编排中补齐。AI 分类自动化限于提交后台任务、查询、等待和取得建议；结果由用户在现有网页校对和审批，本次工具不提供确认或驳回命令。
