# 采用前后端分离支持跨设备收藏管理

2026-10-09，用户明确要求本人在电脑和手机的多设备使用，并提出采用前后端分离。前端为仅输入密码即可登录的网站，后端承担共享收藏数据与刷新任务的管理，支持本地或公开服务器部署；相对于单机本地方案，这一方向便于多个设备访问同一收藏库，同时增加后端部署与维护责任。首版只收藏公开页面，按一千个网站以内的规模设计与验收；首版仅联网使用，离线缓存放在后续阶段。软件自身的密码登录不涉及登录被收藏网站。

后续技术选型已确定由后端 worker 执行快照采集，采用 Preact/Django/SQLite 和 Playwright/Monolith，见 ADR-0004、ADR-0005 及 technical-stack.md；不再作为待选项。
