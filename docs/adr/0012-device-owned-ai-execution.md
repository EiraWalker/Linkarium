# AI 分类由发起设备执行

2026-10-21，Issue #9。替代 ADR-0011 中的服务器模型传输，保留其单次插件收藏自动应用权限以及其他入口的人工校对边界。

云端负责材料、完整消息、共享分类体系、批次、租约、版本校验与事务提交。Firefox MV3 后台负责本机 OpenAI 兼容请求；不安装额外服务。服务器 worker 永不领取 classification/ai_test，历史服务器模型入口失败关闭；ProviderSecret 保留但不用于推理。本机设置、供应商密钥和响应缓存仅使用 storage.local。

ExecutionDevice 属于 runtime，以 owner 会话登记随机设备 ID 和随机 proof 的摘要。原始 proof 仅由插件保存；它补充会话和 CSRF，不取代登录。不设置跨库外键。Job、ImportBatch、ExtensionSubmission 记录发起设备，只有它能领取、恢复、续约和回传，不提供转交。设备丢失时取消旧任务，再发起新任务。

LocalAIRequest 是现有 Job 的阶段检查点，绑定完整 prompt、schema、输入版本、generation/epoch 和摘要。首次共享规划由一个已绑定任务协调，其余任务等待同一检查点。恢复领取轮换尝试与租约；未变的输入允许原设备复用完整缓存。过期、取消、替代、人工编辑或恢复切库都不能借旧授权写入。阶段完成、方案写入、自动应用和任务结束在同一业务库事务中保存；重复回传按请求 ID 和响应摘要返回同一收据，同请求不同内容冲突。

插件每设备串行处理一个请求。完整非流式响应先持久化，再回传；收到匹配摘要的收据才清理。未获得完整响应时仅能重做未完成阶段，不承诺 token 续传或上游恰好一次。后台卸载后由持久记录、alarms 和启动唤醒恢复。用户暂停阻止后续调用，当前完整响应仍先保存。响应上限 512 KiB，分类 120 秒、规划 240 秒，保留每批 10 项及导入授权预算；重新授权未完成模型调用仍占用导入请求预算，缓存重传不占用。

站点内容脚本仅为固定来源、顶层普通标签页提供固定 API 路由，使用 owner Cookie 和 CSRF。网页仅可发起受限业务请求、查看脱敏设备状态和打开插件设置，不能得到密钥或指挥模型传输。来源权限按配置申请，模型请求拒绝重定向、工具调用、非完整响应及非回环明文 HTTP。更换来源不自动继承旧密钥。

library 0006 与 runtime 0006 分别迁移。旧无主活动模型任务标记 LOCAL_EXECUTOR_REQUIRED，不暗中交给在线设备；历史收藏、方案与凭据保留。受信旧版恢复注册新迁移，验收目标使用实际最新迁移构造。部署服务器与升级插件需协调，旧插件不会自动获得本机推理能力。

采集与推理共享输入版本保护：准备 prompt 前等待未完成的元数据采集及正在运行的快照，运行中的 prompt 阻止同一批网站开始新采集；排队快照在结果检查点之后继续。配置验证与分类共用本设备模型传输串行锁，密钥继承由后台根据实际已存来源判断。缓存写入失败保留当前内存结果并明确暂停，服务端也记录 storage_blocked；恢复前不自动重新推理。
